# Compatibility-scanner-in-OldMarket
ENG:
If anyone doesn't know, OldMarket is a special project to create a convenient app store for old android devices.  My project was created to help you find and install applications from there. I wouldn't mind if someone improved it and made it better, but even now it performs its functions. Just indicate that the author of the idea is "seffer".
To use it, either download the "OldMarket viewer" file and rename it to "OldMarket viewer.html ". Alternatively, go to its source code and copy it to an empty text file and rename it to html as well.
